사냥매크로 펌웨어 업데이트

USB로 기기를 연결한 뒤 아래 버튼을 눌러주세요
진행 순서
1. USB 케이블로 기기를 PC에 연결
2. 아래 "업데이트 시작" 버튼 클릭
3. 뜨는 창에서 연결된 포트 선택 → 연결
4. 자동으로 굽는 동안 케이블을 뽑지 마세요
5. 완료되면 자동으로 재시작됩니다
이 브라우저는 지원하지 않아요.
크롬(Chrome) 또는 엣지(Edge)로 이 페이지를 열어주세요.
USB 연결 권한이 차단되어 있어요.
브라우저 설정에서 이 사이트의 USB 권한을 확인해주세요.
문제가 있으면 판매자에게 문의해주세요.
